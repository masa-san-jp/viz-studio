# Viz Studio — データに、雰囲気を与える

CSV / JSON のデータを貼り付けると、three.js の3Dビジュアライズを生成し、
「気分のつまみ」を動かすだけで全体の雰囲気をその場で調整できる、単一ファイルのWebアプリ。

## つかいかた
- ブラウザで `index.html` を開くだけ（ビルド不要・外部依存なし）。
- 「データと列」を開いて CSV か JSON配列（1行目=見出し）を貼り「反映」。列を X／高さ／奥行き／色 に割り当て。
- **粒 / 柱** を選ぶ。ドラッグで回転・ホイールで拡大。

## 気分のつまみ（1本で複数のパラメータが同時に動く）
- **温度** — 寒色・静謐 ⇄ 暖色・熱
- **ドラマ** — 穏やか・平坦 ⇄ 劇的・そそり立つ（高さ・発光・コントラスト）
- **エネルギー** — 静寂 ⇄ 躍動・鼓動（回転・脈動）
- **空気感** — 澄んだ夜 ⇄ 霧・幻想（フォグ・空気）
- **密度感** — 繊細・ひとつぶ ⇄ 濃密・光の塊

## 技術
three.js（r140・`three.min.js` 同梱）。色を選ぶような原始的なUIでなく、感情・雰囲気を直感で調整するUXを志向。

## 用語としての用例・思想的背景

「CSVの値を柱の高さへ割り当て、温度とドラマを調整してグラフの雰囲気を比較する」のように、データの形と表現を探索する道具です。個別の描画パラメータを並べる代わりに、感情・雰囲気に結びつくつまみで複数の値を動かすUXを目指しています。表現を変えた際も、値や軸の読み取りやすさを確認してください。

## 技術的背景と開発経緯

[index.html](index.html) に入力処理、UI、three.jsによる描画、画像保存をまとめ、[three.min.js](three.min.js) を同梱しています。[2026年7月23日の更新](https://github.com/masa-san-jp/viz-studio/commit/aa377086e4a08e78daa7b9eec45aef7f9a6e4cda) で読み取りやすい3D棒グラフを追加し、[PNG書き出しの更新](https://github.com/masa-san-jp/viz-studio/commit/dc57a072ebe8d2c13e274bc34130522a79713bc0) で黒・白・透明背景の出力に対応しています。

## 展開

試した表現は画面内の「画像を保存（PNG）」から持ち出せます。グラフの視点や雰囲気を変えた結果を比較し、共有前に軸・数値・ラベルが伝わるか確認してください。ブラウザやデータ量に応じた描画品質・性能の検証は別途必要です。
